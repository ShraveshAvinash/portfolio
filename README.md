## Deploy on GitHub Pages

1. Create a new **public** GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root. `index.html` must be at the top level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. After GitHub finishes deploying, visit `https://YOUR-USERNAME.github.io`.

GitHub Pages can take a few minutes to publish after a push.

## Use a custom domain

GitHub Pages hosting is free. If you own a custom domain, such as `shraveshmani.com`, you can connect it in **Settings → Pages → Custom domain**.

Add the custom domain in GitHub **before** changing your DNS records. Then add the DNS records required by your domain registrar and enable **Enforce HTTPS** once it becomes available. See the [official GitHub Pages custom-domain guide](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site).

## Preview locally

Open `index.html` directly in a browser, or start a local server from this folder:

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.
