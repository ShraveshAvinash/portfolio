# Shravesh Mani | Cybersecurity Analyst

Personal portfolio website for **Shravesh Mani**, a Cybersecurity Analyst focused on vulnerability management, endpoint investigations, identity security, and practical risk remediation.

## Highlights

- Responsive, mobile-friendly single-page portfolio
- Clear overview of cybersecurity expertise, experience, education, and certifications
- Expandable experience details and accessible navigation
- Direct email contact and downloadable resume
- No framework, build step, or server required

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Manrope and DM Mono

## Preview locally

Open `index.html` directly in a browser, or start a local server from this folder:

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Update the site

| What to change | File |
| --- | --- |
| Portfolio text, links, and resume filename | `index.html` |
| Layout, colours, and responsive styling | `styles.css` |
| Navigation, animations, and expandable roles | `script.js` |
| Downloadable resume | `Shravesh-Mani-Resume.pdf` |
